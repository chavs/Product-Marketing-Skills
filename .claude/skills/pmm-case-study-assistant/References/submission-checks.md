# Submission Checks

Detail for checks 2 to 6 of Phase D in `SKILL.md`. Every check flags and asks. None rewrites the candidate's text.

## 2. Grading-criteria coverage

- Take the criteria from the Phase A recap. Stated criteria come first. Label implied criteria as "implied".
- Output a table: criterion, where the draft addresses it (section and a short quote), and "covered" or the gap.
- A criterion with no home in the draft is the first thing to report.

## 3. Cross-section consistency

Check across every task's answer:
- The same term is used for the same thing (a feature should not have three names).
- The same number appears wherever a number repeats.
- Recommendations do not contradict each other (a pick in one task that another task argues against).
- Claims about the company match the Track 0 baseline.

## 4. Length

- Count with a script, not by eye. If the draft is a file, count the file. If it was pasted, save it to the interview-prep folder first, then count. For example, `Measure-Object -Word` in PowerShell or `wc -w`.
- Report words, pages or slides per section and in total, against the limit and unit from the Phase A recap. For pages, ask for the exported page count. Do not estimate.
- Run the count the first time a full draft exists, not only at the end.
- If over the limit, list cut candidates by section: repeated points, hedges, setup that comes before the answer. Do not write the cuts.

## 5. Plain-writing flags

List where the draft has any of these. Give the section and the first few words of the sentence. List locations only. Do not supply replacement text.
- Em dashes.
- Sentences over about 25 words.
- Flourish: metaphors, rhetorical questions, stacked adjectives.
- Stock phrasing that reads as machine-written, such as "in today's fast-paced world" or "it is important to note".

## 6. AI-use note

- Write one only when the company asks how AI was used (from Phase A) or the candidate wants one.
- Draft 3 to 5 plain sentences from what actually happened in this session: which research tracks ran, which sources were read, that critique was flagged and not rewritten, and that the candidate wrote the answers.
- State only what is true of this session. If the candidate used AI elsewhere, they add that.
- The candidate confirms or edits the note before sending.
